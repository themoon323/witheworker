# 보강 분석 결과 (측정모형·판별타당도·조절 양상·공통방법편의)

실행 환경: R 4.3.3, lavaan 0.6-17, semTools 0.5-6, psych 2.4.1, sandwich 3.1-0. N=318. 모든 모형은 사전 지정 후 추정했으며 수정지수 기반 수정·문항 삭제·문항묶음을 하지 않음.

- 표준화 적재치: 전 문항 유의. 범위 — 리더십 .626–.818, 일의의미 .713–.865, 주인의식 .446–.869, 조직지원 .496–.854, 혁신행동 .671–.874.

- **모든 수준에서 조건부 효과가 유의** → "조직지원인식이 높을수록 효과가 강해진다"는 양상이지, 특정 수준에서 효과가 사라지는 양상이 아님. 단순기울기의 유의/비유의 대비로 조절을 서술하면 안 되는 사례.
- Johnson–Neyman: 주인의식 경로의 비유의 경계는 ZW=-2.360(원점수 1.446, 표본 하위 극단)으로 관측 범위[-2.925, 2.144] 내이긴 하나 극소수 영역. 일의의미 경로 경계(-3.503)는 관측 범위 밖(외삽).

### 강건성 (사전 지정 목적: 상호작용 추정의 안정성 점검)

| 점검 | 일의의미 경로 | 주인의식 경로 |
|---|---|---|
| 원모형 (OLS SE) | B=.0441, p=.091 | B=.0451, **p=.028** |
| HC3 강건 SE | p=.134 | **p=.053** |
| 제곱항(ZX², ZW²) 포함 | B=.0675, p=.468 | B=.0749, p=.308 |

- **주인의식 경로의 상호작용은 강건하지 않음**: HC3 적용 시 p=.053으로 경계선, 제곱항 통제 시 비유의(단, 제곱항 모형은 다중공선성으로 검정력이 낮아지는 보수적 점검임).
- ΔR²도 .005로 작음. 두 경로의 ΔR²(.005 vs .005)와 B(.044 vs .045)가 거의 같다는 점에서, **"한쪽은 유의, 한쪽은 비유의"를 "두 경로의 조절효과가 다르다"로 해석해서는 안 됨**(두 상호작용 계수 차이의 직접 검정은 수행하지 않았으며, p=.091 vs p=.028은 그 근거가 아님).
- 원고 서술 권고: 조절효과를 "주인의식 경로에서 유의하게 나타났다"로 보고하되, 효과 크기가 작고 강건 SE에서 경계선임을 한계에 명시.

## 4. 공통방법편의 보조 진단

- Harman 단일요인: 최종 분석 46문항(통제변수 제외), Pearson 상관행렬, 무회전. **PCA 첫 성분 47.63%** (고유값>1 성분 6개), PAF 단일요인 46.52%.
- 단일요인 CFA(위 표)는 5요인보다 극히 불량(ΔCFI=.177).
- 해석 지침: 첫 성분이 50% 미만이고 단일요인 모형이 기각되지만, **이는 공통방법편의의 부재를 입증하지 않음**(동일 응답원·동일 시점 자료의 한계로 서술). 마커변수는 조사되지 않았으므로 사용하지 않음.
