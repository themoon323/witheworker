# 방법·결과 서술 초안 + 원고 문장 처리 목록 + 전문가 확인사항

## A. 한국어 방법·결과 서술 초안 (확인된 결과에 한정)

> 아래 초안은 이번 재현·보강 분석에서 실제 수행하고 확인한 내용만 담았다. 전문가 원출력과의 수치 대조가 끝나기 전에는 기존 원고의 수치를 교체하지 말 것. [대괄호]는 원고 확정 전 선택·확인이 필요한 부분.

### 방법 (분석 절차 단락 초안)

가설 검증에 앞서 측정모형의 적합성과 판별타당도를 확인하기 위해 확인적 요인분석을 실시하였다. 5점 리커트 문항의 특성을 고려하여 강건 최대우도법(MLR)을 주 추정법으로 사용하고, 순서형 추정법(WLSMV)으로 민감도를 확인하였다. 가설 검증은 첫째, 임파워링 리더십이 일의 의미와 심리적 주인의식을 매개로 혁신행동에 미치는 간접효과를 두 매개변수를 동시에 투입한 병렬매개모형으로 검증하였으며, 간접효과의 유의성은 부트스트랩 5,000회의 95% 백분위 신뢰구간으로 판단하였다. 둘째, 조직지원인식의 조절효과는 독립변수와 조절변수를 표준화한 후 상호작용항을 투입하는 위계적 회귀분석으로 검증하였다. 모든 분석에서 성별, 연령, 교육수준, 재직기간을 통제하였다(N = 318).

### 결과 (초안)

**측정모형.** 연구 구성개념을 구분한 5요인 모형은 χ²(979) = 2180.50, CFI = .882, RMSEA = .066 [90% CI .062, .070], SRMR = .055로 나타났으며, 하위차원을 반영한 10요인 모형은 χ²(944) = 1537.59, CFI = .942, RMSEA = .047로 더 양호하였다. 5요인 모형은 임파워링 리더십과 조직지원인식을 통합한 모형(Δχ²(4) = 147.00, p < .001), 심리적 주인의식과 조직지원인식을 통합한 모형(Δχ²(4) = 119.93, p < .001), 일의 의미와 심리적 주인의식을 통합한 모형(Δχ²(4) = 209.42, p < .001), 단일요인 모형(Δχ²(10) = 881.77, p < .001)보다 유의하게 우수하였다. 다만 잠재요인 상관은 심리적 주인의식–조직지원인식 .867, 임파워링 리더십–조직지원인식 .826으로 높았고, HTMT도 각각 .874 [95% CI .801, .934], .857 [.803, .909]로 보수적 기준(.85)을 상회하여, 구성개념 간 변별이 제한적일 수 있다는 점을 연구의 한계에서 논의하였다.

**병렬매개.** 임파워링 리더십의 총효과는 유의하였다(B = .625, p < .001). 두 매개변수를 동시에 투입했을 때 임파워링 리더십은 일의 의미(B = .682, p < .001)와 심리적 주인의식(B = .738, p < .001)에, 일의 의미(B = .354, p < .001)와 심리적 주인의식(B = .413, p < .001)은 혁신행동에 유의한 영향을 미쳤으며, 직접효과는 유의하지 않았다(B = .079, p = .131). 부트스트랩 결과 일의 의미를 경유한 간접효과(B = .241, 95% CI [.144, .344])와 심리적 주인의식을 경유한 간접효과(B = .305, 95% CI [.204, .416])가 모두 유의하였다. [추가 보강으로 보고할 경우: 두 간접효과 차이의 부트스트랩 신뢰구간은 영을 포함하여(B = −.064, 95% CI [−.228, .100]) 두 매개경로의 상대적 크기가 다르다고 보기 어려웠다.]

**조절효과.** 조직지원인식과 임파워링 리더십의 상호작용은 심리적 주인의식에 대해 유의하였으나(B = .045, p = .028, ΔR² = .005), 일의 의미에 대해서는 유의하지 않았다(B = .044, p = .091, ΔR² = .005). 단순기울기 분석 결과 임파워링 리더십이 심리적 주인의식에 미치는 효과는 조직지원인식이 낮을 때(−1SD) B = .177, 평균일 때 B = .222, 높을 때(+1SD) B = .267로 모든 수준에서 유의하였으며, 조직지원인식이 높을수록 그 효과가 강해지는 양상이었다. [한계 서술 권고: 상호작용의 효과크기(ΔR² = .005)가 작고, 이분산에 강건한 표준오차를 적용하면 유의수준 경계(p = .053)에 있으므로 해석에 신중을 기할 필요가 있다.]

**공통방법편의.** 모든 변수를 단일 시점에 동일 응답원으로부터 수집하였으므로 공통방법편의 가능성을 점검하였다. 최종 분석 문항 46개에 대한 무회전 주성분분석에서 첫 성분의 설명분산은 47.63%였고, 단일요인 CFA는 측정모형보다 적합도가 현저히 낮았다. 다만 이러한 결과가 공통방법편의의 부재를 보증하지는 않으므로 연구의 한계로 논의하였다.

## B. 기존 원고 문장 처리 목록

### 유지 가능 (재현으로 뒷받침됨)
1. 두 간접효과가 모두 유의하다는 결론 및 방향.
2. 조절효과가 심리적 주인의식 경로에서만 통계적으로 유의하다는 결론(p 기준).
3. 척도 구성 서술: 일의 의미 10문항 중 1개 제외 후 9문항, 조직지원인식 8문항 중 1개 제외 후 7문항, 리더십 12문항, 주인의식 9문항, 혁신행동 9문항. (단, 제외 사유를 "역문항"으로 쓸지는 아래 확인사항 1 참조)
4. N = 318, 통제변수 4종.

### 수정 권고
1. **"두 경로의 조절효과가 서로 다르다/주인의식 경로에서 더 크다"는 취지의 서술** → 두 상호작용 계수(.044 vs .045)와 ΔR²(.005 vs .005)가 사실상 같으므로, "유의/비유의"의 대비만으로 차이를 주장하는 문장은 삭제·완화.
2. **두 매개효과의 크기를 비교하는 서술이 있다면** → 차이 검정 비유의(CI [−.228, .100])이므로 삭제하거나 신규 검정 결과로 교체.
3. **단순기울기를 "낮을 때는 효과 없음, 높을 때 효과 있음"식으로 서술했다면** → 모든 수준에서 유의하므로 "높을수록 강해짐"으로 수정.
4. **판별타당도가 확보되었다고 단정하는 서술** → 통합모형 대비 우수성(Δχ²)은 성립하나 Fornell-Larcker 위반 5쌍, HTMT>.85 2쌍이므로 "대안모형 비교에서는 지지되나 일부 구성개념 간 상관이 높아 변별이 제한적"으로 수정하고 한계에 명시.
5. **혁신행동 3차원(창출·전파·구현) 서술** → 자료의 하위차원 변수는 2차원(창출/전파·구현 통합)으로 저장됨. 이론 서술은 유지하되 측정·분석 수준의 차원 수와 불일치하지 않게 조정.
6. **조절회귀 절차 서술** → 실제 파일은 "평균중심화"가 아니라 "전체 표준화(Z) 후 곱" 방식. 원고에 평균중심화로 기재했다면 표준화로 수정(또는 전문가에게 실제 절차 확인).

### 확정 보류 (전문가 원출력 대조 전)
1. 모든 표의 구체 수치(M, SD, α, B, SE, R², CI). 결론 방향은 재현되었으나 수치 단위 대조표(보고서_02)의 전문가 칸이 비어 있음.
2. 부트스트랩 CI 끝값(난수에 따라 달라짐 — 원고에는 어느 한 실행의 값을 쓰되 seed 명시 권장).
3. CFA 관련 기존 서술(기존 원고에 EFA/CFA가 어떤 형태로 있었는지 미확인).

## C. 통계 전문가에게 재확인할 사항

1. **일의의미3·조직지원6의 처리 경위**: 저장된 값 기준 두 문항 모두 전체점수와 정(+)의 상관(r=.36/.19). (a) 원자료에서 이미 역채점된 값인지, (b) 역채점 없이 제외만 했는지, (c) 제외 사유가 "역문항"인지 "낮은 신뢰도 기여"인지. 원고의 "역문항 1개 제외" 표현의 정확성에 직결됨.
2. **통제변수 투입 형태**: 연령을 연속(@연령)으로 썼는지 연령대(1–4)로 썼는지, 학력(1–6)·재직기간(1–4)을 연속으로 넣었는지 더미로 넣었는지. (민감도 분석상 결론은 불변이나 계수 대조에 필요) + @학력 1–6, @현직장근속통합 1–4의 범주 의미(값 라벨 부재).
3. **PROCESS 설정**: 실제 사용한 PROCESS 버전, Model 4의 시드, CI 방식(백분위 vs 편의수정 BC). 원고에는 백분위로 기재되어 있으나 PROCESS 기본값은 백분위(v3+)이므로 출력으로 확인.
4. **조절회귀 절차**: 평균중심화가 아닌 Z표준화 후 곱 방식이 맞는지(파일 역산으로는 Z방식 확정). 단계 구성(1단계 통제 → 2단계 주효과 2개 → 3단계 상호작용)이 원고 표와 같은지.
5. **표본 처리 이력**: 과거 300명·281명 자료와 318명 최종 자료의 관계(최초 수집 수, 제외 기준·단계). 원고의 표본 서술과 일치시키기 위해 필요.
6. **기업 ID 부재**: 여러 기업에서 표집했다면 기업 군집효과를 통제하지 않은 한계를 원고에 쓸지 여부.
7. **전문가 원출력 파일(.spv/명령문/결과 PDF)과 원고 표**: 수치 단위 대조 완성에 필수.
