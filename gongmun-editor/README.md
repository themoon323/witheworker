# 공문·보고서 편집기

한국 공공기관 문서 작성에 특화한 웹 편집기입니다. 두 가지 문서를 다룹니다.

- **보고서·제안서** (기본): 공공보고서 작성 기준(대통령비서실 「보고서 품질향상 연구팀」 표준)의 양식 — 장·절 `Ⅰ.` `1.` `1)`, 항목 `□` `o` `-` `·`, 주석 `※`, 참고 박스, 표지·목차, 머리말·쪽 번호. 휴먼명조 15pt·헤드라인 22pt·줄간격 130%·여백 위아래 15mm 좌우 20mm.
- **공문(기안문·시행문)**: 행정안전부 「행정업무운영 편람」과 「행정업무의 운영 및 혁신에 관한 규정」의 작성 기준 — 항목 기호 8단계, '끝.' 표시, 두문·결문.

일반 워드프로세서가 사람에게 맡기는 기호·번호·들여쓰기·표기 규칙을 편집기가 직접 처리하고, 결과를 **한글 문서(HWPX)**로 내보냅니다.

## 바로 쓰기

- **설치 없이**: `dist/gongmun-editor.html` 파일 하나를 내려받아 브라우저(크롬·엣지·웨일)로 엽니다. 인터넷이 없어도 편집·검사·PDF 불러오기·인쇄·HWPX/DOCX 내보내기가 됩니다(AI 작성만 인터넷이 필요합니다).
- **개발용**: `npm start`로 `http://localhost:8080`에서 엽니다 (ES 모듈이라 `index.html`을 파일로 직접 열면 동작하지 않습니다).

## 보고서·제안서 모드

- **새 문서**에서 보고서(기본)·사업 제안서(표지·목차)·워크숍 결과 보고·회의 결과 보고 서식을 고르거나, **열기**로 마크다운(.md) 파일을 엽니다.
- A4 화면에서 바로 씁니다. Enter는 같은 종류의 다음 줄(장·절 제목 다음은 □), Tab·Shift+Tab은 `장 → 절 → 소제목 → □ → o → - → ·` 순서로 수준을 옮깁니다. 툴바의 줄 종류 목록으로 문단(서술식)·※ 주석으로 바꿀 수 있습니다.
- 기호와 번호는 자동입니다. 장을 옮기거나 지우면 Ⅰ. Ⅱ.와 절 번호가 다시 매겨지고, 목차도 장·절 제목으로 저절로 만들어집니다.
- **표**, **박스**(참고·요청 사항), **쪽 나눔** 버튼, **굵게**(Ctrl+B). 마크다운이나 □·o 기호가 있는 글을 붙여 넣으면 수준을 읽어 줄로 나눕니다.
- **문서 정보** 탭: 제목·부제·날짜·부서·머리말, 표지·목차·쪽 번호, 항목 기호(□ o - · / □ ○ - · / □ ㅇ - ·). **서식** 탭: 글꼴(본문·제목·주석), 크기, 줄간격, 들여쓰기, 여백.
- **검사**: 날짜·시각·금액·쌍점·물결표 표기, 행정용어 순화, 같은 상위 항목 아래 하위 항목이 하나뿐인 곳, 너무 긴 문장(2~3줄 초과), 수동태('추진되었음'), 기호를 손으로 한 번 더 쓴 줄.
- **초안 가져오기 → AI로 보고서 작성**: 메모·회의 기록·PDF를 결론 먼저, 근원 원인, 정책대상 규모·소요 예산을 갖춘 보고서로 다시 씁니다(만들 문서: 정책기획 보고서, 사업 제안서, 결과 보고서, 회의 결과 보고, 상황·현안 보고, 검토 보고).
- 내보내기: **한글(HWPX)**, 인쇄·PDF(머리말·쪽 번호 포함), 텍스트 복사, 문서 파일(.json).

### 마크다운 → 한글 명령줄 변환기

Claude와 대화하면서 md를 주고 한글 파일을 받는 용도입니다(저장소의 `.claude/skills/report-hwpx` 안내).

```bash
node scripts/md2hwpx.mjs 보고서.md -o 보고서.hwpx --png 미리보기.png
```

md 형식은 `src/markdown.js` 맨 위 설명에 있습니다. 요약하면 머리 정보(`제목:` `날짜:` `부서:` `표지: 예` `목차: 예` `기호:`), `##` 장 / `###` 절 / `####` 소제목, `-` 목록(깊이별 □ o - ·) 또는 줄 앞에 □·o 기호, `※` 주석, `>` 참고 박스, 표 위의 `<표 1> 제목`·`(단위: 명)`, `<!-- 쪽나눔 -->`, `**굵게**`.

## 공문 모드: 초안에서 한글 공문까지

1. **초안 가져오기**를 누르고 **PDF 불러오기**로 초안 PDF를 고르거나(툴바의 **열기**로 PDF를 골라도 됩니다), 초안 글을 붙여 넣습니다.
2. 초안이 이미 공문 형식이면 **그대로 구조화**, 메모·줄글·보고서 형식이면 **AI로 공문 작성**을 누릅니다.
3. 검사 결과와 AI가 남긴 '확인할 점'을 보고 고친 뒤, 결문(결재 라인·연락처)을 채웁니다.
4. **한글(HWPX)** 로 내보내 한글에서 엽니다. 워드가 필요하면 **DOCX**, 종이·PDF는 **인쇄·PDF**.

### PDF 불러오기

- PDF의 글자 조각 좌표로 줄을 다시 묶고, 줄 끝이 오른쪽 끝까지 찼는지·줄 간격·항목 기호를 보고 끊긴 줄을 이어 붙입니다. 쪽 번호는 뺍니다.
- 공문 PDF라면 행정기관명, 수신·(경유)·제목, 항목 수준, 붙임을 알아보고, '끝.' 뒤의 발신명의·결문은 본문에 넣지 않습니다.
- 글자가 거의 없는 **스캔 PDF**는 AI 작성에서 Claude가 PDF 화면을 직접 읽습니다(글자 인식 프로그램 없이).
- 한계: 글꼴 정보가 빠진 일부 PDF는 글자가 깨질 수 있습니다. 표는 줄 단위 글로 들어옵니다.

### AI로 공문 작성 (Claude)

- 줄글 초안을 「1. 관련 → 2. 목적·요청 → 가. 나. 세부 사항」 구조와 공문 문체·표기(날짜, 24시각제, 금액 한글 병기, 쉬운 우리말)로 다시 씁니다. 초안에 없는 사실은 지어내지 않고 ○○로 비운 뒤 '확인할 점'으로 알려 줍니다.
- 내려받은 편집기: 사용자의 **Claude API 키**(Claude Console, console.anthropic.com에서 발급)로 Claude API를 직접 호출합니다. 모델은 Claude Opus 5.5(`claude-opus-5-5`), 응답은 JSON 스키마로 고정(구조화 출력)하고, 안전 분류기가 거절하면 서버가 다른 모델로 다시 시도하는 기능(`fallbacks: "default"`)을 켭니다. 키는 '이 브라우저에 기억'을 고를 때만 이 브라우저(localStorage)에 저장됩니다.
- claude.ai 아티팩트: 키 없이, 보는 사람의 Claude 계정으로 호출합니다(첫 호출 때 허용을 묻습니다).
- **개인정보 주의**: AI 작성을 누르면 초안(스캔 PDF는 파일 자체)이 Anthropic으로 전송됩니다. 개인정보·비공개 정보는 지우고 보내십시오. 인터넷이 되지 않는 업무망(망분리 환경)에서는 AI 작성을 쓸 수 없고, 나머지 기능은 그대로 됩니다.
- 되돌리기(Ctrl+Z)로 AI 작성 전 문서로 돌아갈 수 있습니다.

### 한글(HWPX) 내보내기

- 한컴 오피스로 만든 빈 문서의 머리 정보(글꼴·스타일)를 바탕으로 글자·문단 모양을 만들어 넣습니다. A4·공문 여백, 항목 기호와 내어쓰기('내어 쓰기용 자동 탭'), 제목 아래 선, 표(머리행 음영), '끝.', 발신명의, 결문 선을 담습니다.
- 확인한 것: OWPML 공식 스키마(XSD) 검사, 패키지 구조 검사, 한글 열기 안전성 검사(python-hwpx 도구)를 통과합니다. **실제 한컴 오피스 한글에서 열어 보는 확인은 아직 하지 못했습니다.** 화면과 다르게 보이는 곳이 있으면 알려 주십시오.
- claude.ai 아티팩트에서는 저장 기능이 `.hwpx` 확장자를 받지 않아 `.hwpx.zip`으로 저장됩니다. 파일 이름 끝의 `.zip`을 지우면 한글에서 열립니다.

## 공문 모드에서 특화된 것

| 공문 규칙 | 편집기가 하는 일 |
|---|---|
| 항목 기호 `1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮` | Tab / Shift+Tab으로 수준만 바꾸면 기호와 번호가 자동으로 매겨지고, 항목을 옮기거나 지워도 다시 매겨집니다. `하.` 다음은 `거.`로 이어집니다. |
| 하위 항목은 상위 항목에서 2타(한글 1자)씩 들여쓰기, 둘째 줄부터는 내용 첫 글자에 맞춤 | 내어쓰기(매달린 들여쓰기)를 자동 적용합니다. 스페이스로 맞출 필요가 없습니다. |
| '끝.' 표시 | 본문 끝, 붙임 끝, 표 아래(1자 띄움)에 자동으로 붙고, 표가 중간에서 끝나면 '이하 빈칸'을 넣습니다. 따로 입력하지 않습니다. |
| 붙임 | 하나면 번호 없이, 둘 이상이면 `1. 2.`로 번호를 붙이고 끝에 온점을 찍습니다. |
| 두문·본문·결문 구성 | 행정기관명, 수신·(경유)·제목, 발신명의(관인생략·서명생략), 수신자 목록, 결재 라인(전결·대결), 생산등록번호(처리과명-일련번호)와 시행일, 접수, 우편번호·도로명주소·누리집, 전화·팩스·전자우편, 공개 구분을 서식 그대로 배치합니다. |
| 수신자가 둘 이상이면 '수신자 참조' | 검사기가 찾아내고, 고치기를 누르면 결문의 수신자 목록으로 옮깁니다. |
| A4, 여백 위 30mm·왼쪽 20mm·오른쪽 15mm·아래 15mm | 화면이 곧 인쇄 결과입니다. 인쇄했을 때 쪽이 바뀌는 위치를 점선으로 보여 줍니다. 여백은 바꿀 수 있습니다. |

### 공문 검사기

입력하는 동안 다음을 점검하고, 대부분은 **고치기** 한 번으로 바로잡습니다.

- 날짜: `2026년 10월 7일`, `2026.10.07`, `2026-10-07` → `2026. 10. 7.` / 존재하지 않는 날짜
- 요일: `2026. 10. 15.(수)` → 실제 요일 `(목)`으로
- 시각: `오후 3시 20분`, `14시 30분` → `15:20`, `14:30` (24시각제, 쌍점)
- 금액: `113,560원` → `금113,560원(금일십일만삼천오백육십원)`
- 쌍점·물결표 띄어쓰기: `관련 : ` → `관련: `, `10. 7. ~ 10. 9.` → `10. 7.~10. 9.`
- 행정용어 순화: 금번→이번, 익일→다음 날, 별첨→붙임, ~토록→~하도록, 가이드라인→지침 등
- 직접 타자한 항목 기호(`가. …`)를 자동 번호 항목으로 바꾸기, 항목이 하나뿐인데 기호를 붙인 경우
- 필수 요소 누락: 제목, 수신, 발신명의, 처리과명, 전화번호, 비공개 근거(정보공개법 제9조제1항 각 호), 붙임 수량

### 그 밖의 기능

- **기존 공문 가져오기**: 한글·워드·메일에서 복사한 공문이나 PDF를 넣으면 수신·제목·붙임과 항목 기호를 읽어 자동 번호 문서로 바꿉니다. 본문에 여러 줄을 붙여 넣어도 같은 방식으로 구조화합니다.
- **서식**: 협조 요청, 자료 제출 요청(수신자 참조), 회의·행사 개최 알림, 회신, 계획 보고(내부결재). 새 서식을 골라도 기관명·결재 라인·연락처는 이어 씁니다.
- **표기 도우미**: 날짜(요일 포함)·시각·금액을 규정 표기로 바꿔 커서 위치에 넣습니다.
- **내보내기**: 한글(HWPX), DOCX(워드·한글), 인쇄·PDF(A4), 텍스트 복사(온-나라 등에 붙여넣기), 문서 파일(.json) 저장·열기, 자동 저장, 되돌리기.

## 단축키

| 키 | 동작 |
|---|---|
| Enter | 같은 수준의 다음 항목 (빈 항목에서 누르면 상위 수준으로) |
| Tab / Shift+Tab | 하위 항목 / 상위 항목 (표 안에서는 다음·이전 칸) |
| Shift+Enter | 항목 안에서 줄 바꿈 |
| Backspace (항목 맨 앞) | 상위 수준으로, 문단이면 앞 항목과 합치기 |
| Alt+Shift+↑/↓ | 항목 위아래로 옮기기 |
| Ctrl+Z / Ctrl+Shift+Z | 되돌리기 / 다시 실행 |
| Ctrl+S | 문서 파일로 저장 |
