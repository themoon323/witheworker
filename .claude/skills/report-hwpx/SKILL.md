# 보고서·제안서 → 한글(HWPX)

변환기: `gongmun-editor/scripts/md2hwpx.mjs` (외부 의존성 없음, node만 필요)

## 순서

1. **내용 기준을 먼저 적용한다.** 사용자의 `public-report` 스킬이 있으면 읽고(수요자·요청사항·유형 확정, 결론 먼저, 근원 원인, 정책대상 규모, 목차 확인), 초안을 그 기준에 맞게 다시 쓴다. 초안에 없는 사실은 지어내지 말고 ○○로 비운 뒤 사용자에게 알린다.
2. **md로 정리한다.** 아래 형식을 따른다.
3. **변환하고 검사 결과를 고친다.**
   ```bash
   cd gongmun-editor
   node scripts/md2hwpx.mjs 입력.md -o 결과.hwpx --png 미리보기.png
   ```
   출력의 [오류]·[표기]는 md를 고쳐 다시 변환한다. [권장]은 판단해서 반영한다.
4. **미리보기 그림을 직접 열어 확인한다** (Read로 PNG 확인). 기호·들여쓰기·표·쪽 나눔이 의도대로인지 본다.
5. **검증한다** (python-hwpx가 있으면): `python3 -m hwpx.tools.validator 결과.hwpx`
6. 사용자에게 .hwpx 파일을 보내고(SendUserFile), 확인할 점(비워 둔 ○○ 등)을 짧게 알린다.

## md 형식

```markdown
---
제목: 2026년 ○○ 사업 추진 계획
부제: (선택)
날짜: 2026. 10. 8.
부서: ○○과
표지: 예          # 제안서처럼 표지가 필요할 때
목차: 예          # 5쪽이 넘을 때
머리말: 없음      # 생략하면 ('26. 10. 8., 제목, 부서)로 자동
기호: □ o - ·     # 기본값. ○, ㅇ 등으로 바꿀 수 있음
---

## 장 제목            → Ⅰ.  (번호는 자동, 손으로 쓴 번호는 지움)
### 절 제목           → 1.
#### 소제목           → 1)

□ 핵심 항목           (또는 - 목록: 깊이에 따라 □ → o → - → ·)
  o 내용
   - 세부
※ 자료: 출처          → 주석

<표 1> 표 제목        → 표 바로 위 줄이면 표 제목
(단위: 명)            → 단위
| 구분 | 2025 |
|---|---|

> **참고**            → 회색 참고 박스 (첫 줄 굵게 = 박스 제목)
> 내용

<!-- 쪽나눔 -->        → 쪽 나눔
**굵게**, <u>밑줄</u>
```

서식(사용자 public-report 스킬의 형식 규격): A4, 여백 위·아래 15mm·좌우 20mm(머리말·꼬리말 10mm), 본문 휴먼명조 15pt, 제목 HY헤드라인M 22pt, 참고·주석 HY중고딕 13pt, 줄간격 130%, 머리말 오른쪽 정렬, 쪽 번호 '- 1 -'.

## 한계

- 그림은 넣지 못한다 (한글에서 직접 넣도록 안내).
- 실제 한컴 한글에서 연 모양은 사용자가 확인해야 한다. 어긋난 곳을 알려 주면 `src/reportHwpx.js`를 고친다.
- 발주처가 정한 양식(HWP 서식 파일)이 있으면 그 양식이 우선이다. 이 변환기는 양식이 자유일 때의 기본형이다.
